OpenHabLogViewer is a Node.js + TypeScript app with an Express backend and a small browser client. It tails openHAB log files (events.log and openhab.log), parses timestamped and continuation lines, keeps bounded buffers server/client side, and renders a live log UI via Server-Sent Events. Source files live under src/client and src/server. The current log row layout shows time, file/source badge, level, logger, and message.
