After changes, run the existing validation commands: npm run typecheck, npm test, and npm run build. Do not introduce new tooling (no linter/formatter/mocking library). Unit tests are mandatory for newly written or changed code in src/server or src/client, per docs/UNIT_TESTS.md (colocated *.test.ts, node:test + node:assert/strict, no mocking framework); a bug fix needs a regression test. Keep behavior backward-compatible unless the task explicitly changes UX, and update README.md/docs/ARCHITECTURE.md only when directly affected by the change. See docs/ARCHITECTURE.md, docs/CONTRIBUTING.md, and docs/UNIT_TESTS.md for the full conventions.
